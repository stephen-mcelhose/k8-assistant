# Attribution — Raw Tutorial Sources

The files in `docs/wiki/raw/tutorials/` are verbatim plain-text extractions of
pages from [kubernetes.io](https://kubernetes.io).

kubernetes.io documentation is published under the
**Creative Commons Attribution 4.0 International (CC BY 4.0)** licence:
https://creativecommons.org/licenses/by/4.0/

Each file includes its source URL and fetch date in a comment header.

These files are stored in version control to enable the quarterly diff/sync
strategy described in `docs/wiki/tutorial-sync-plan.md`: re-fetch the page,
diff against the stored snapshot, and re-ingest only if the content changed.

The files are generated by `docs/wiki/raw/extract.py` and are immutable
after creation — do not edit them manually.
